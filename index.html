EUROMAG-3D — Geophysical Telemetry & 3D Visualization

Stack: OpenGL / OpenGL ES, .NET, Java (Android SDK), Bluetooth SPP

Commercial companion software built for geomagnetic field research devices to detect underground anomalies such as water tables, cavities, and mineral deposits. Both Windows desktop and Android applications pair with handheld hardware via Bluetooth serial (HC-05/HC-06) to stream sensor coordinates and magnetic readings into real-time interactive 2D/3D terrain grids.

  • • Implemented a custom .mag3d survey file format supporting save/load across sessions.
  • • Built live OpenGL 3D mesh and 2D heatmap rendering with configurable grid dimensions, color palettes, height/color scaling, and rotation sensitivity.
  • • Added export pipelines to Excel-compatible sheets and 3D mesh files for external analysis.
